# FinLedger AI

AI-Powered Organizational Finance Monitor.

## Setup Instructions

1. **Install dependencies:**
   From the root folder, run:
   ```bash
   npm install
   cd server && npm install
   cd ../client && npm install
   ```

2. **Environment Variables:**
   Create `.env` in `server/` and `client/` as needed.

3. **Run Dev Servers:**
   From the root folder, run:
   ```bash
   npm run dev
   ```
